# 🎬 Clips Vault (Архив клипов с друзьями)

Стильный минималистичный сайт в премиальной тёмной теме для хранения, организации и просмотра нарезок и хайлайтов с друзьями.

## 🚀 Как запустить
Откройте файл `index.html` в любом браузере (Chrome, Edge, Firefox, Safari и др.) — сервер не требуется!

## ⚡ Особенности
- **Премиальный тёмный дизайн**: глубокий матовый графит, сдержанная контрастность, отсутствие вырвиглазного неона.
- **Полная персонализация**:
  - Настройка названия сайта и сквада;
  - Выбор иконки / эмодзи логотипа (🎬, 🔥, 🎮, ⚡, 💀, 👑, 🎯, 🧊);
  - Цветовые акценты (Платина / Монохром, Индиго, Изумруд, Янтарь, Рубин);
  - Плотность сетки карточек (2, 3 или 4 колонки).
- **Локальное сохранение видео**:
  - Drag & Drop видеофайлов (MP4, WebM, MOV, MKV, AVI);
  - Сохранение прямо в браузере через `IndexedDB` (видео не пропадают при перезагрузке).
- **Интерактивный плеер**:
  - Таймкоды ключевых моментов с перемоткой в один клик;
  - Реакции (`😂`, `💀`, `🤡`, `🔥`, `🗿`);
  - Оценка момента от 1 до 10.
- **Фильтры и поиск**:
  - Фильтрация по участникам (`@samurai_669`, `@Nenomernoj` и т.д.);
  - Быстрый поиск по фразам и тегам.
